# Validation plan

## Objective

Evaluate whether CaseGraph improves controlled dispute-investigation performance without increasing unsafe action selection.

## Minimum interpretation boundary

Synthetic controlled-study results support conclusions only about the evaluated task and participant population. They do not automatically establish real merchant operational impact.

## Recommended workflow

Run a small pilot first, discard pilot data from confirmatory analysis, freeze the protocol, collect complete paired participants, export blinded qualitative responses, and run the paired participant-level analysis.

If the study is not completed, do not make quantitative claims such as percentage time reduction or accuracy improvement in public materials.
